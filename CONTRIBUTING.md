# Contributing

Run the Python tests, TypeScript check and Next.js production build before proposing changes. Never commit `.env`, source uploads, local databases or provider responses containing private information. Use synthetic sources in fixtures.

Engine changes need a realistic positive case and a nearby negative case. Preserve scope, qualifiers and quotation provenance. Model-dependent tests use explicit mocks; record live experiments separately. Do not describe authored outputs as model inference.

Keep PromiseGraph reusable and independent of API/UI dependencies. Credit reused code and verify licenses. Follow the organizer's development window and record actual work honestly.
