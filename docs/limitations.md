# Known limitations

- Live Gemma is unverified on this host because no backend key is configured. Model-backed extraction, semantic review, alternatives and drafting are implemented and mocked in CI; they need a real multimodal run before making a Gemma-track claim.
- Image-derived wording remains approximate; no OCR coordinates or verified crops are fabricated. Image financial values are provisional. Text evidence confirms quote presence, not document truth/authenticity.
- Candidate matching uses normalized category/subject/predicate buckets without embeddings; semantically equivalent but differently extracted wording may be missed. Unknown scope downgrades findings, so low-context sources often need clarification.
- Local single-user app; no authentication, encryption at rest, production worker queue or public sharing. Loopback Host/origin restrictions are practical prototype protections, not a multi-user security architecture. Use one API worker.
- Limits: 12 sources/dossier, 12 MB/source, 20 unencrypted PDF pages, 60,000 text characters and 20 megapixels/image. PDF page previews/model rasters are bounded to 1600px. These limits do not guarantee provider token/image capacity or short latency.
- Jobs use an in-process worker. Reanalysis can change extraction IDs/wording and replace results; changed findings need new review. Review history records previous claims/findings, but there is no full immutable versioned analysis archive.
- Calculator uses Decimal arithmetic and preserves quoted monetary precision for scoped claims; legacy numeric records may have earlier float precision. Original extracted amounts still require review; no currency conversion, tax estimate, duration multiplication or assumed refundability is performed. Unreviewed totals are provisional.
- Eligibility evaluates only explicit extracted fields and never saves profiles. It does not decide admission or scholarship outcomes. Dependencies do not impose order between conditions unless documented; no generic attendance/assignment requirements are invented.
- Clarification edits are local to the current view until copied; generated drafts persist. No messages are sent. Alternative interpretations are suggestions with validated claim IDs; their prose still needs human review.
- Legacy issue listing suppresses consistent pairs. ScopeGuard/PromiseLab can explicitly return consistent or insufficient-evidence results; an empty issues list does not prove authenticity.
- PDF reports use ReportLab base fonts (rupee signs converted to INR); broader scripts need an embedded licensed font. JSON/Markdown preserve Unicode. Browser download-event automation was unavailable; native direct download links and API report content were checked.
- URL fetching, public monitoring, source deletion within an active dossier, browser extensions, email parsers, embedding retrieval, multilingual evaluation and hosted deployment remain deferred.
- Git is connected to `shoaib2000857/Hacktoberfest-2026-NIAT-KKH`, branch `promisetrap`. Public visibility and an eventual published release must be verified externally. No changes were pushed and no event submission was made during this enhancement. The organizer main branch has not been edited.
